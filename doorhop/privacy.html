한국어

통통 탈출은 개인정보를 수집하지 않습니다. 계정, 광고, 분석 도구, 인터넷 연결 없이 기기 안에서만 동작합니다.

1. 적용 대상

이 방침은 CH.KIM(chunghyun1995)이 제작한 게임 「통통 탈출(Doorhop)」의 Android 앱, Windows 앱(Microsoft Store), 웹 버전에 적용됩니다.

2. 수집하는 개인정보

수집하지 않습니다. 이름, 이메일, 전화번호, 위치, 연락처, 사진, 기기 식별자, 광고 ID 등 어떠한 개인정보도 수집·저장·전송하지 않습니다.

3. 기기에 저장되는 정보

게임을 이어서 하기 위해 다음 정보만 사용자의 기기 안에 저장합니다. 이 정보는 개인을 식별할 수 없으며 외부로 전송되지 않습니다.

  • 진행 상황: 클리어한 스테이지, 스테이지별 별 기록, 실패 횟수
  • 별 상점: 사용한 별, 구입한 꾸미기, 장착한 꾸미기
  • 직접 만든 맵: 맵 만들기에서 저장한 맵과 클리어 여부
  • 설정: 언어, 테마, 소리 크기, 그래픽 품질, 화면 모드와 해상도(PC)

맵 공유 코드는 사용자가 복사·붙여넣기 버튼을 누를 때만 기기의 클립보드를 사용하며, 게임이 코드를 외부로 보내지 않습니다.

앱을 삭제하면 함께 삭제됩니다. 웹 버전은 브라우저 저장소에 저장되며, 브라우저의 사이트 데이터를 지우면 삭제됩니다.

게임은 인터넷 연결을 사용하지 않으며, Android에서 별도의 권한을 요청하지 않습니다.

5. 광고, 분석, 결제

광고, 사용자 분석·추적 도구, 제3자 SDK, 인앱 결제를 포함하지 않습니다.

7. 아동의 개인정보

English

Doorhop does not collect any personal data. It runs entirely on your device, with no accounts, ads, analytics or internet connection.

1. Scope

This policy applies to the game “Doorhop (통통 탈출)” by CH.KIM (chunghyun1995) on Android, Windows (Microsoft Store) and the web.

2. Personal data we collect

None. The game does not collect, store or transmit any personal data, such as your name, email, phone number, location, contacts, photos, device identifiers or advertising ID.

3. Data stored on your device

To let you continue playing, the game stores only the following on your own device. It cannot identify you and is never sent anywhere.

  • Progress: cleared stages, best star counts, and number of fails
  • Star shop: stars spent, items bought and items equipped
  • Your maps: maps saved in the map maker and whether you cleared them
  • Settings: language, theme, volume, graphics quality, and display mode and resolution (PC)

Map share codes use your device clipboard only when you press the copy or paste button. The game never sends codes anywhere.

Uninstalling the app deletes this data. The web version stores it in your browser's site storage, which you can clear at any time.

4. Permissions and network

The game does not use the internet and does not request any Android permissions.

5. Ads, analytics and payments

The game contains no ads, no analytics or tracking tools, no third-party SDKs and no in-app purchases.

6. Web version

The web version is hosted on GitHub Pages. When the page loads, GitHub may process server logs such as your IP address under the GitHub General Privacy Statement. This page loads its font from Google Fonts.

7. Children

The game does not collect personal data from anyone, including children.

8. Changes

If this policy changes, the update will be posted on this page with a new effective date.

9. Contact

For privacy questions, please open an issue on GitHub.
